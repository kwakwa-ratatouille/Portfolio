# Portfolio — Matis Rodrigues Photographie

Portfolio photo (sport, spectacle, reportage) destiné aux demandes d'accréditation.

- `src.html` : source de la page
- `data.json` : séries et métadonnées des images
- `media/` : images
- `node build.cjs` : régénère `index.html` (site) et `artifact.html`
